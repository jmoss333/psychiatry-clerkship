# Future Development Roadmap

Inventory summary: 11700 candidate resources; 605 keep, 8553 revise, 2542 archive; 2785 duplicate/version groups flagged.

## Phase 1 - Organize Existing Resources

- Create the proposed directory skeleton.
- Move or link only PHI-safe education resources into the library.
- Keep raw source packets in `Archive/Raw_Source_Packets` with a source log.
- Confirm duplicate/version recommendations before deleting anything.

## Phase 2 - Revise Outdated or Clinician-Facing Material

- Convert long manuals and decks into MS3-length modules.
- Strip internal branding when the resource should function as generic medical education.
- Standardize reading time, learning objectives, and expected competencies.

## Phase 3 - Create Missing Clerkship Resources

- Orientation packet, daily workflow guide, oral presentation guide.
- MSE/interview pocket reference.
- Consult psychiatry, capacity, delirium, catatonia, withdrawal modules.
- OSCE and shelf review materials.

## Phase 4 - Develop Multimedia

- Curate existing therapeutic videos and audio into student-relevant playlists.
- Build short faculty-recorded explainers only where existing materials do not cover the objective.
- Add transcripts and accessibility metadata.

## Phase 5 - Integrate AI-Assisted Learning

- Create prompt templates for de-identified case formulation, differential diagnosis, and oral presentation practice.
- Add guardrails: no PHI, no unsupervised clinical decision-making, cite source documents.

## Phase 6 - Publish a Polished Library

- Convert the curated source into a student-facing website or single-file HTML index.
- Add separate role tracks: MS3, sub-I, resident, social work, nursing, patients/families.
- Establish quarterly review and version control.
