# Primary Source Download List — Adult Inpatient Psychiatry Clerkship

**For:** Joshua Moss, MD · **Use:** download the actual PDFs via MaineHealth institutional access and file them beside the Landmark library so trainees read primary sources, not summaries.
**Citations** are drawn from your Landmark Teaching Guide + standard instrument sources. Lookup key = **first author · year · journal**; titles are given so you can paste straight into PubMed or the journal. *Verify volume/page before any formal citation.*

> **How to pull efficiently at MaineHealth**
> 1. **PubMed** → search the title → click the journal/**"Find It @ MaineHealth"** (LinkResolver) for full text.
> 2. **LibKey / LibKey Nomad** (browser extension) gives one-click PDF on PubMed/Google Scholar through your institution — fastest for a batch like this.
> 3. Direct publisher access is covered for **NEJM, The Lancet (+ Lancet Psychiatry), JAMA/JAMA Psychiatry, AJP, Br J Psychiatry, Schizophrenia Bulletin, Cochrane** via the MaineHealth Library proxy.
> 4. For anything paywalled with no full text, the **MaineHealth Library document-delivery / ILL** service will retrieve it.
> Access flags below: 🔓 usually open-access · 🔒 paywalled but covered by your access · 📕 book (library/ILL).
