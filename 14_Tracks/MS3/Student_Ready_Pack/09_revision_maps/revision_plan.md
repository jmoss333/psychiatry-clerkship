# Revision Plan For Existing Materials

Generated: 2026-06-27

## Goal

Convert existing internal manuals manuals, resident readings, slide decks, scripts,
and clinician-facing implementation guides into student-ready MS3 clerkship
materials without losing clinical depth.

## Global Conversion Rules

1. Replace internal framework language with plain clinical language unless the
   framework itself is the teaching point.
2. Keep each student-facing handout to one objective, one skill, and one action.
3. Put advanced theory in faculty notes or optional reading.
4. Convert long decks into short handouts plus a facilitator guide.
5. Convert scripts into role-play prompts, OSCE stations, or sample language.
6. Convert implementation guides into workflow checklists.
7. Never use real patient examples unless rewritten as synthetic composites.

## Translation Table

| Source Type | Current Problem | Student-Ready Product | Example Conversion |
|---|---|---|---|
| internal manual chapter | Too much internal vocabulary | 1-2 page clinical concept handout | "Stabilization" becomes sleep, substances, medical contributors, medications |
| internal family scripts | Patient/family-facing and branded | Student family-meeting language bank | "Supporting without enabling" becomes boundary + validation scripts |
| Resident article cards | Too advanced or paper-heavy | "What changes on rounds?" brief | One paper, one clinical move, one discussion question |
| Slide decks | Presentation-dependent | Handout + facilitator notes | 40 slides become 1-page student summary + 10-minute teaching plan |
| Clinician implementation guide | Operational detail-heavy | Student workflow checklist | "Discharge bridge" becomes barriers, safety, follow-up, handoff |
| Patient/family handouts | Useful but not teaching-facing | Supervised education guide | Students learn when to use a handout and what to say before/after |
| NotebookLM audio | No transcript/objectives in student path | Optional audio with learning objective | Add "listen for X" and 3 recall questions |

## Revision Targets

### 1. Internal manuals

**Use for**

- Formulation structure.
- Family-system thinking.
- Discharge planning.
- Recovery/identity after hospitalization.

**Student-ready modules to create**

- Four-layer formulation in plain language.
- Family context on rounds.
- Discharge as a clinical intervention.
- Medication conversations with families.

**Do not import directly**

- Internal terminology that requires a long preamble.
- Publication-oriented figures without explanatory captions.
- Branding-heavy language for external-facing students.

### 2. Resident-Level Readings

**Use for**

- Faculty prep.
- Optional deeper dives.
- Article club.

**Student-ready products**

- Required: one-page "why this matters on inpatient psychiatry" summaries.
- Optional: original article, podcast/audio, or chapter.
- Faculty: teaching script and answer key.

**Priority reads**

- Engel on biopsychosocial formulation.
- Robins and Guze on diagnostic validity.
- Appelbaum on capacity.
- Stanley/Brown safety planning.
- Inouye delirium.
- Bush-Francis catatonia.
- CATIE, STAR*D, STEP-BD, lithium/suicide, clozapine.
- Brown/Leff family expressed-emotion papers.

### 3. Slide Decks

**Use for**

- Faculty teaching.
- Visual summaries.
- Optional student review.

**Student-ready products**

- 10-minute mini-lesson.
- 1-page summary.
- 3 discussion questions.
- 1 skill practice.

**Revision checklist**

- Remove duplicate title slides and version labels.
- Add learning objectives.
- Add "what the student should do tomorrow on rounds."
- Add source and date.
- Add PHI/composite case statement.

### 4. Scripts

**Use for**

- Role-play.
- OSCE standardized-patient prompts.
- Example language.

**Student-ready products**

- "Try saying" language banks.
- Family-call role plays.
- Collateral consent practice.
- Difficult-conversation debrief prompts.

**Revision checklist**

- Strip performative narration.
- Preserve clinically useful phrases.
- Add what the student should listen for.
- Add attending escalation triggers.

### 5. Clinician-Facing Implementation Guides

**Use for**

- Workflow.
- Safety.
- Documentation.
- Systems-based practice.

**Student-ready products**

- Daily workflow checklist.
- Discharge barrier map.
- Family-meeting agenda.
- Consult psychiatry checklist.
- Epic note quality checklist.

## Quality Bar

A student-ready resource is done when:

- A student can use it in under 10 minutes.
- It names the clinical situation where it applies.
- It has one concrete behavior to practice.
- It avoids unexplained jargon.
- It has no PHI.
- It has a faculty-review date.

Plain-English note: this is the bridge between the existing library and the
clerkship. It says what to keep, what to simplify, and what to move into faculty
notes so the student curriculum stays usable.
