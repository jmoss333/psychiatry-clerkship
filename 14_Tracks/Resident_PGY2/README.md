# Track — Resident (PGY-2)

A 4-week compression of the MS3 spine with resident-level overlays.

**What this track adds**
- **ACGME milestone mapping** for each week (patient care, medical knowledge, systems-based practice, professionalism).
- **Teach with the library:** use the 10-minute **Teaching Script Template** to present a landmark paper at rounds (`07_Evidence_and_Reading/Landmark_Library`).
- **Supervision & evaluation templates** (`13_Faculty_Resources`).
- The **Clinical Implementation Spine** (family meeting playbook, first-three-sessions, risk-stratified discharge) in `06_Family_and_Relational`.
- The Resident 2-page handout + Facilitator answer keys.

**Ordered path:** Weeks 1–2 (foundations + mood/psychosis/pharm) → Week 3 (psychotherapy/personality + run a family meeting) → Week 4 (acute + disposition + teach one paper). Supervise a student through one OSCE.
