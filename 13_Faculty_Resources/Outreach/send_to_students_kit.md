# Sending the Hub to Students — Kit

**Link:** https://une-ms3-psychiatry.netlify.app
**QR code:** `clerkship_hub_qr.png` (this folder) — points to the same link.
**Access:** private by URL (hidden from Google; no login). Anyone with the link can open it — fine for teaching content, but assume it can be forwarded.

## Recommended channels (in order)
1. **Pre-arrival email (Day −7)** — the primary push; snippet below.
2. **Day-1 orientation packet** — paste the link + drop in the QR so they can open it on their phone at first rounds.
3. **Posted on the unit** — print the QR on the workroom one-pager; students scan when they have a minute.

The site is mobile-responsive and the audio + quizzes work on a phone, so the QR is the highest-yield path for on-the-go use.

## Before a wide send — quick checklist
- [ ] **Attestation:** clear the "pending faculty review" banners on content you're comfortable with (use **Faculty → Review & Attest**). The 145 new quiz questions are AI-drafted — spot-check before students rely on them.
- [ ] **Optional gating:** if you want light access control, Netlify can add a single site-wide password (Site settings → Access & security → Visitor access — paid feature). Default of "private by URL" is usually enough.
- [ ] **Optional polish:** rename the Netlify subdomain or attach a custom domain for a cleaner link (e.g., a memorable short URL) — Site settings → Domain management.
