# APP psychiatry fellowship pathway — implementation and gap traceability

Status date: 2026-09-22. This register distinguishes software, clinical content, local policy, and real supervision. It is not faculty attestation, a local-policy record, an accreditation determination, or evidence that a learner or fellowship is ready. The APP route is a resident-build preview pending a human production-host decision.

State vocabulary: **implemented** means software exists and has focused test evidence; **drafted** means review material exists outside learner builds; **not started** means no new deliverable was created here; **requires faculty input**, **requires institutional policy**, and **requires real observation** are unresolved human dependencies.
