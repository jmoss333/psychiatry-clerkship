Icon spec

One 24-unit grid, one compound stroke path per glyph, colour always inherited. The stroke width is set per rendered size so a 16 px tab icon and a 24 px heading icon draw the same ~1.4 px line.

24 × 24 grid · 2-unit live-area margin (dashed) · round caps and joins · no fills · stroke="currentColor"

Colour: three roles, nothing else

Default · currentColor = text-mid
A: --fd-text-mid #64574b / #bcb0a2 · B: --rc-text-mid. Never text-dim or --rc-text-light (fails 3:1 in some places).
Active / current = teal-deep
A: --fd-teal-deep · B: --rc-accent-dark. It follows the label's colour; it is never set on the icon alone.
Safety / crisis = danger, only
A: --fd-danger (✚ redrawn as safety) · B: --rc-danger (life-buoy). No other icon is ever red.
Site B category badges are the single exception. There the icon takes the badge's existing category token (8 roles; Family → --rc-cat-family-strong on --rc-cat-family-light, 6.46:1). Forced-colors: icons inherit CanvasText / Highlight, with no forced-color-adjust override.
